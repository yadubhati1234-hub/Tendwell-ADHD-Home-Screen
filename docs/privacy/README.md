# Privacy policy page

`index.md` is the public privacy policy that Play Console requires. It is served by GitHub Pages from the `/docs` folder of `main`.

One-time setup (repo owner):

1. Placeholders are filled (developer db10apps, support db10apps@gmail.com). Update the date at the top whenever the policy changes.
2. Repo Settings, Pages, "Deploy from a branch", branch `main`, folder `/docs`. Save.
3. After a minute or two the policy is live at `https://yadubhati1234-hub.github.io/Tendwell-ADHD-Home-Screen/privacy/`.
4. Paste that URL into Play Console, App content, Privacy policy, and into the store listing.

Keep this page and the Play Data safety form in sync when features change (for example when analytics events are added).
